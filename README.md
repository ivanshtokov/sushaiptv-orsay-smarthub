# SushaIPTV Orsay SmartHub

Русский | [English](README.en.md)

IPTV-приложение для Samsung Smart TV на платформе Orsay. Три вкладки содержат снимки M3U-плейлистов, которые вы добавляете при сборке.

## Установка

Нужны Samsung Orsay с Apps Sync, компьютер с Python 3.9+ и три M3U-файла. После установки телевизору нужен интернет для потоков; для обновления плейлистов потребуется новая сборка.

- [Установка](docs/installation.md)
- [Инструкция для агента](docs/agent-installation.md)

## Управление

Влево и вправо переключают вкладки, вверх и вниз выбирают канал. OK запускает поток, повторный OK открывает его на весь экран. Return возвращает список. INFO открывает QR-код Telegram.

## Проверка

```sh
python3 -m unittest discover -s tests -v
node tests/test-remote.js
```

На Samsung UA32J4303 проверены отдельные функции предыдущей версии. Установку версии 0.111 и воспроизведение без компьютера на телевизоре ещё нужно проверить. Подробнее: [проверки](TESTING.md), [архитектура](docs/architecture.md).

Плейлисты и ZIP могут содержать приватные ссылки. Храните их вне репозитория. Лицензия кода пока не указана.
