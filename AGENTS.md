# Agent instructions

SushaIPTV is a Samsung Orsay widget. Follow [the installation runbook](docs/agent-installation.md) for discovery, commands and user-facing prompts.

- Check the repository root, Git status and active services before changes.
- Preserve existing Apps Sync entries and packages. The built-in server serves only SushaTV.
- Keep playlists and ZIPs private. Do not claim TV playback or standalone operation without a device check.
- Keep changes separate from SushaMedia.
